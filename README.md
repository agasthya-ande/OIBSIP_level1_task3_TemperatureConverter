# OIBSIP_level1_task3_TemperatureConverter

Description

A web application that converts temperatures between Celsius, Fahrenheit, and Kelvin using a simple and user-friendly interface.

Features

- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Kelvin to Celsius
- Fahrenheit to Kelvin
- Kelvin to Fahrenheit
- Input Validation

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download the project files.
2. Open index.html in a web browser.
3. Select a conversion type and enter the temperature.
